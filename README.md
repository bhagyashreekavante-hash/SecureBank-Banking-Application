My project is called **SecureBank – Banking Application**. It is a full-stack web application developed using Java, Spring Boot, MySQL, HTML, CSS, and JavaScript.

The frontend provides the user interface, while Spring Boot handles backend processing and business logic. MySQL is used for persistent data storage. I have organized the backend into separate layers, including controllers, services, repositories, entities, DTOs, and mappers, to make the code modular and maintainable.

The main objective of the project is to understand how a banking web application connects its frontend, backend, and database using a structured software architecture.
